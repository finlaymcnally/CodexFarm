# Problem Statement

`codex-farm` retried generic codex failures, including HTTP `429` rate-limit responses. That can amplify API pressure and make throttling worse.

# Acceptance Criteria

- A detected `429`/rate-limit codex failure is terminal on first hit (no requeue retry loop).
- Worker/process emits clear warning text containing `429`.
- `process` stops additional task claims after the first rate-limit failure.
