# Analytics dashboard flow discovery

`codex_exec_activity.csv` already contains enough per-call context (status, durations, tokens, source/pipeline/run/task metadata) to build a full static dashboard without touching DB state.

Durable implementation rule from this exploration:

- Keep dashboard generation read-only against telemetry input files.
- Keep `index.html` inline JSON payload plus JS fetch fallback (`assets/dashboard_data.json`) so opening dashboard files directly (`file://`) still works in restrictive browser setups.

Command entrypoint and code paths:

- CLI: `codex-farm stats-dashboard`
- Collector/renderer: `src/codex_farm/analytics_dashboard.py`
- Contract docs: `docs/07-analytics/07-analytics_readme.md`
