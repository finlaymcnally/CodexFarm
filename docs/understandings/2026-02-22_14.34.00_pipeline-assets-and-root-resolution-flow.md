# Pipeline assets and root-resolution flow

Key discovery from tracing `cli.py`, `paths.py`, `pipeline_spec.py`, and `worker.py`:

- Root selection is a strict precedence chain: `--root` -> `CODEX_FARM_ROOT` -> auto-discovery from cwd/module path.
- A candidate root is valid only if it has `pipelines/`, `prompts/`, and `schemas/` directly under it.
- Pipeline JSONs are validated with `PipelineSpecModel` (`extra=forbid`), then prompt/schema paths are resolved relative to the pack root and must exist.
- Run creation persists absolute `farm_root` always, and persists `workspace_root` only when explicitly passed.
- Worker execution prefers those persisted config values, which stabilizes resume/retry behavior even if caller defaults/environment changed later.
- Final Codex `--cd` is: persisted workspace override first, otherwise pipeline `codex_cd_mode` (`asset_root`, `input_dir`, `input_file_dir`).
