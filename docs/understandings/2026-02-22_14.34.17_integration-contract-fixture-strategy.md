# Discovery

Chunk 06 intentionally uses two deterministic fixture styles:

- Monkeypatch `codex_farm.worker.run_codex_exec` for fast assertions on CLI JSON contracts, queue status, and run/task reporting.
- Fake `codex` executable on `PATH` for subprocess-level assertions (`--cd`, prompt substitution, output-file handoff) through `codex_exec`.

Using only one style leaves a blind spot: monkeypatch misses subprocess argument regressions, while fake-binary-only tests are slower and less focused for CLI payload contract checks.
