# Discovery

- `process --json` intentionally keeps stdout machine-clean (single final JSON object) and sends creation/progress lines to stderr.
- `run create` and `process` have different glob defaults:
- `run create` uses fixed `"**/*.json"` unless overridden.
- `process` treats empty `--glob` as "use pipeline `input_glob_default`".
- Run config persistence is part of CLI contract:
- `farm_root` is always persisted as an absolute path.
- `workspace_root` is only persisted when explicitly provided.
- `one` treats `codex_cd_mode=input_dir` and `input_file_dir` the same (input file parent), unlike run-based worker flow.
