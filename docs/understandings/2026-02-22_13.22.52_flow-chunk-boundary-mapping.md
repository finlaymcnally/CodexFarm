# Discovery

The code naturally separates into six boundaries: CLI contract, pipeline/root resolution, persistent queue state, worker retry loop, Codex+schema acceptance gate, and integration contracts. This split follows the real call path (cli -> db/run setup -> worker -> codex_exec -> schema validation -> status/reporting) and keeps most changes local to one chunk plus an adjacent seam.
