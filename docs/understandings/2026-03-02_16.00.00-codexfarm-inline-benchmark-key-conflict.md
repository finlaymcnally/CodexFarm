---
summary: "Resolved a pipeline prompt mode regression risk from duplicate JSON keys during inline migration."
read_when:
  - When validating inline prompt mode behavior for migrated recipe pipelines.
---

- Migrated prompt templates now use `{{INPUT_TEXT}}` and benchmark payload artifacts in worker tests now verify prompt bodies contain inline JSON payloads.
- While reviewing shipped assets, I found `pipelines/recipeimport.benchmark.line_label.v1.json` briefly had both `"prompt_input_mode": "inline"` and `"prompt_input_mode": "path"`.
- JSON preserves the last duplicate key, so this made mode resolution effectively `path`, which would have broken inline-contract intent for that benchmark pipeline.
- Removing the stray duplicate key restores the intended inline mode and aligns runtime contract checks, linting, and plan/test expectations.
