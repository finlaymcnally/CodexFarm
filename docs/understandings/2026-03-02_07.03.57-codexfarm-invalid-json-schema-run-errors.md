  - "When pass2/pass3 codex-farm runs fail with schema-validation rejections"
  - "When debugging run errors that still show noisy generic warnings"

- Added explicit `invalid_json_schema` detection in both direct command execution (`src/codex_farm/cli.py`) and worker execution (`src/codex_farm/worker.py`) by parsing stderr/stdout tails for `invalid_json_schema`.
- Failed single-command runs now store `failure_category="invalid_json_schema"` in forensics, and worker failures now treat `invalid_json_schema` as terminal, same as authentication failures.
- This preserves the detailed schema-rejection message for `run errors` and avoids downstream masking as `no last agent message`.
