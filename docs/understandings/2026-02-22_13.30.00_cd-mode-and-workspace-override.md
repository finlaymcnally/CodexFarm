# cd-mode and workspace override

`--workspace-root` is now treated as an explicit override, not a default.

Behavior discovered and implemented:

- `one`:
  - if `--workspace-root` is set, use it for Codex `--cd`.
  - else use pipeline `codex_cd_mode`.
  - in `one`, `input_dir` and `input_file_dir` both resolve to `Path(--in).parent`.

- `process` / `run create` / `go`:
  - run config always stores `farm_root`.
  - run config stores `workspace_root` only when user passed `--workspace-root`.
  - worker reads those persisted values for resumed/retried tasks.

- worker `--cd` resolution:
  - explicit `workspace_root` in run config wins.
  - otherwise:
    - `asset_root` -> run `farm_root`
    - `input_dir` -> run `input_dir`
    - `input_file_dir` -> task input file parent
  - missing computed directory is a terminal configuration error (task marked `error` immediately).
