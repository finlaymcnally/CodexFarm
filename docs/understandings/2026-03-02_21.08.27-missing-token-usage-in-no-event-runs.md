---
summary: "Why recent telemetry rows had blank tokens and how fallback capture now behaves."
read_when:
  - "When token fields appear blank in codex_exec_activity.csv"
---

Recent rows with empty `tokens_*` were from pytest fake-Codex executions (`input_path` under `/tmp/pytest-*`) where no JSONL events were emitted.

`run_codex_exec` previously populated token fields only from `turn.completed.usage`, so `codex_event_count=0` meant blank token columns.

Fallback now estimates tokens (`chars_div_4`) when usage is entirely missing and marks provenance in `usage_json` (`estimated=true`).
