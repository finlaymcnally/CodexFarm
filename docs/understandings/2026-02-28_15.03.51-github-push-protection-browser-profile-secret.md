## Discovery

GitHub Push Protection evaluates the commits being pushed (`origin/master..HEAD`), not only the latest tree state.

In this incident, commit `c70c24f` introduced a Chromium profile/cache dump under a path beginning with `\\wsl.localhost\...\.oracle\browser-profile/...`, including a cached JS file containing a Mapbox secret token. A later commit deleted those files, but push remained blocked because the secret still existed in history.

## Forward Prevention

`.gitignore` now includes rules to ignore browser-profile and Chromium cache artifacts so these files are less likely to be committed again.
