summary: "Where reasoning-token counts appear in Codex usage payloads and how telemetry captures them."
read_when:
  - "When you need reasoning-token totals from codex_exec_activity.csv or run telemetry --json"
---

Codex usage payloads can include reasoning-token counts under nested token-details objects, not only top-level token keys.

Current capture path reads `reasoning_tokens` from either:
- `usage.output_tokens_details.reasoning_tokens`
- `usage.completion_tokens_details.reasoning_tokens`

Telemetry now writes this as additive CSV field `tokens_reasoning` so callers can audit reasoning spend separately from `tokens_output`.
