# Root/workspace flow discovery

`process` and `run create` must persist `farm_root` and `workspace_root` in `runs.config_json`, because workers can resume later in a different shell where cwd/env are different.

Worker behavior should be:

- parse run `config_json`
- use `farm_root` from config to load pipelines (fallback to `--root` on worker command, then auto discovery)
- use `workspace_root` from config as Codex `--cd` (fallback to `farm_root`)

This makes external pipeline packs reliable without requiring callers to `cd` into codex-farm.
