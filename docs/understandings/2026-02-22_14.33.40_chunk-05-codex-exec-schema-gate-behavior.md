Chunk 05 is the acceptance boundary, not just a subprocess wrapper.

Key flow discovered:

- `run_codex_exec` writes to a temp file and only promotes to final output via atomic `os.replace`.
- Non-zero Codex exit is tolerated when a non-empty `--output-last-message` payload exists.
- Final success still requires local JSON Schema validation (`validate_json_file_against_schema`).
- `cli.one` fails immediately on timeout/codex/schema errors; worker mode feeds those errors into retry/terminal-error logic.
- `doctor` mirrors runtime invocation details (global `--ask-for-approval`, `--skip-git-repo-check`) and treats an exact `OK` line as a valid smoke pass even with non-zero exit.
