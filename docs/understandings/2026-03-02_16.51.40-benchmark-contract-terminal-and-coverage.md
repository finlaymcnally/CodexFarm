---
summary: "Clarifies benchmark-mode terminal schema failure handling and pre-fill alignment coverage semantics."
read_when:
  - "When changing recipeimport benchmark task failure categories in worker.py"
  - "When interpreting benchmark pass.metrics.json alignment_coverage"
---

- In benchmark mode, schema validation now runs on the calibrated canonical payload and any resulting `SchemaValidationError` is categorized as `benchmark_contract_error`.
- `benchmark_contract_error` is terminal in worker flow, so benchmark contract mismatches do not consume retry budget.
- `alignment_coverage` should represent observed model coverage, not post-fill completeness.
- The metric is now computed from raw predicted line indices intersected with canonical line indices (`observed_lines / total_lines`), while `aligned_lines` still captures post-fill output cardinality.
