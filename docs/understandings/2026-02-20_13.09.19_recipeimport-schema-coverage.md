The repository now has two example styles for recipeimport data:

- Real run samples (`shaved-carrot-salad.r24.*`) with sparse fields.
- Platonic full-shape samples (`platonic-full.example.*`) with nearly every known field present.

The prior `recipeimport_*_fullshape_v1` schemas required too many fields and rejected real samples. Validation contracts were updated so both styles pass.

For final payloads, `schemas/recipeimport_final_fullshape_v1.schema.json` is now aligned with the canonical recipeimport schema in `examples/recipeimport_final/recipeDraftV1.canonical.recipeimport.schema.json`.
